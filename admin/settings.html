Important security notes

  • Publish Firestore security rules from the repository through Firebase Console.
  • Never share administrator credentials or Firebase private service-account keys.
  • Force logout is delivered when a user's device is online and receives the Firestore update.
  • Password reset sends a secure Firebase reset email; administrators do not see users' passwords.
  • Cloud Functions and push delivery are separate deployment steps and may require a paid Firebase plan.
